\# CircuSave Mobile



\## Purpose



CircuSave Mobile is the primary day-to-day mobile experience for CircuSave organizers and participants.



It allows users to:



\- create an account

\- log in securely

\- create or join savings circles

\- view dashboard information

\- manage circles and activity

\- review contribution and payout information

\- receive reminders and notifications

\- manage preferences and settings

\- access subscription features



The Mobile app is a user interface. It relies on the CircuSave Backend for core business rules, validation, authentication, authorization, and persistent data.



\## Mobile Project Structure



The CircuSave Mobile application is organized into folders based on responsibility.



\### app/



Contains the main Expo Router screens and routes.



Examples include:



\- login

\- create account

\- dashboard

\- circles

\- activity

\- settings

\- subscription

\- support



\### components/



Contains reusable user interface pieces used across multiple screens.



Examples may include:



\- buttons

\- cards

\- inputs

\- headers

\- modals

\- shared visual elements



\### lib/



Contains shared application logic, helpers, services, and reusable functionality.



Examples may include:



\- authentication context

\- API helpers

\- theme configuration

\- billing logic

\- utility functions



\### constants/



Contains shared constant values used throughout the app.



\### assets/



Contains static visual resources such as:



\- images

\- icons

\- fonts

\- branding assets



\### android/



Contains the native Android project generated and used by the Expo/React Native application.



\### node\_modules/



Contains installed JavaScript and TypeScript dependencies.



This folder is generated by the package manager and should not be manually edited.

\## How the Mobile App Starts



CircuSave Mobile uses Expo Router as its entry and navigation system.



When the app opens, the main index route checks the user's authentication status.



The startup flow is:



App opens  

↓  

Authentication status is checked  

↓  

If loading, show a loading indicator  

↓  

If authenticated, redirect to the dashboard  

↓  

If not authenticated, redirect to the login screen



The main startup route is:



app/index.tsx



The authenticated dashboard route is:



app/(tabs)/dashboard.tsx





\## Main Mobile Areas



\### Dashboard



The dashboard is the main authenticated home area.



It gives the user a summary of important CircuSave information and provides access to the main features.



\### Circles



The circles area is where users can view and manage the savings circles they belong to.



\### Create Circle



The create-circle area allows an organizer to start a new savings circle and define its basic structure.



\### Activity



The activity area shows recent circle-related activity and history.



\### Settings



The settings area allows users to manage preferences, account-related options, and application settings.



\### Subscription



The subscription area manages premium or paid CircuSave features.



\### Support



The support area provides help and assistance to users.
